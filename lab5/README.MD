# Лабораторна робота: Обробка винятків у Python

Цей скрипт містить виконання трьох практичних завдань, які демонструють безпечну роботу програми за допомогою конструкції `try...except...finally` та обробку типових помилок.

## Опис завдань

- **Завдання 1 (Ділення чисел):** Запитує у користувача два числа та виконує їх ділення. Демонструє перехоплення помилок `ZeroDivisionError` (спроба ділення на нуль) та `ValueError` (введення літер замість цифр).
- **Завдання 2 (Обробка введення):** Перевіряє введення цілого числа. Використовує блок `finally` для гарантованого виведення повідомлення про завершення програми, незалежно від наявності помилок.
- **Завдання 3 (Безпечна робота з файлами):** Демонструє обробку помилки `FileNotFoundError`. Якщо файл `example.txt` не існує, програма автоматично створює його. Блок `finally` використовується для гарантованого закриття файлу (`file.close()`) та звільнення пам'яті.
