# Лабораторна робота №2 (Варіант 6)

## Опис проекту
У цій лабораторній роботі реалізовано алгоритми обчислення факторіалу, перевірки числа на просте/складене та виведення таблиці множення.

## Завдання
1. Обчислення факторіалу числа 8.
2. Перевірка числа 7 на те, чи є воно простим.
3. Виведення таблиці множення від 1 до 10.
