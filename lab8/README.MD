# Лабораторна робота №8

У цій роботі створено класи для працівників, транспорту та тварин. Реалізовано успадкування класу `Manager` від `Worker`, перевизначення методів і використання поліморфізму для транспорту та тварин.

Програма демонструє основні принципи об'єктно-орієнтованого програмування в Python.
