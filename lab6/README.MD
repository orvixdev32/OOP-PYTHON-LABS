# Лабораторна робота: Функції, модулі та робота зі списками в Python

Цей проєкт містить виконання практичних завдань з використання функцій, лямбда-виразів, стандартних бібліотек Python, а також розробки та підключення власного модуля.

## Структура проєкту

- `lab6.py` — головний файл програми, що містить виконання всіх трьох завдань.
- `list_utils.py` — власний модуль для обробки списків.
- `.gitignore` — конфігураційний файл для ігнорування системної папки `__pycache__/` при завантаженні на GitHub.

---

## Опис завдань

### Завдання 1. Програма-калькулятор
- Реалізовано окремі функції для додавання, віднімання, множення та ділення (з перевіркою ділення на нуль).
- Для операції піднесення до степеня використано лямбда-функцію (`lambda x, y: x ** y`).
- Додано захист від неправильного введення символів за допомогою блоку `try...except ValueError`.

### Завдання 2. Робота з модулем `random`
- За допомогою модуля `random` генерується список із 10 випадкових чисел у діапазоні від 1 до 100.
- Обчислюються та виводяться наступні показники:
  - середнє арифметичне елементів;
  - максимальне та мінімальне значення;
  - кількість парних чисел у списку.

### Завдання 3. Власний модуль `list_utils`
Створено окремий файл-модуль `list_utils.py`, який містить функції для:
1. **Сортування списку** (`sort_list`);
2. **Видалення дублікатів** (`remove_duplicates`);
3. **Пошуку мінімального та максимального елементів** (`find_max_min`).

У головному файлі `lab6.py` виконано імпорт модуля (`import list_utils`) та продемонстровано коректну роботу всіх його функцій.
