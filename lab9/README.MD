# Flask Web Application

Навчальний вебзастосунок, створений у межах лабораторної роботи з дисципліни Python. Проєкт демонструє основи роботи з Flask, маршрутизацію, HTML-шаблони та обробку даних із форм.

## Функціональність

- **Головна сторінка** — привітання та навігація між розділами.
- **Реєстрація** — форма для введення імені, електронної пошти та повідомлення.
- **Результат реєстрації** — відображення введених користувачем даних.
- **Список користувачів** — перегляд усіх зареєстрованих користувачів.
- **Галерея** — окрема сторінка із зображеннями.

## Використані технології

- Python
- Flask
- HTML5
- CSS3
- Jinja2

## Встановлення та запуск

1. Клонуйте репозиторій:

```bash
git clone <repository-url>
```

2. Перейдіть до папки проєкту:

```bash
cd lab9
```

3. Встановіть Flask:

```bash
pip install flask
```

4. Запустіть застосунок:

```bash
python app.py
```

5. Відкрийте у браузері:

```text
http://127.0.0.1:5000/
```

## Маршрути

| Маршрут | Призначення |
|---|---|
| `/` | Головна сторінка |
| `/register` | Форма реєстрації |
| `/users` | Список користувачів |
| `/gallery` | Галерея зображень |

## Зберігання даних

Дані зареєстрованих користувачів зберігаються у списку Python під час роботи застосунку. Після перезапуску сервера список очищується, оскільки база даних у цьому проєкті не використовується.

## Призначення

Проєкт створено з навчальною метою для практичного ознайомлення з можливостями Flask та принципами розробки простих вебзастосунків на Python.
