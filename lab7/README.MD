# Лабораторна робота №7

У цій роботі реалізовано три класи: `Student`, `Car` і `Book`. Програма дозволяє працювати з інформацією про студентів, змінювати та сортувати їхні рейтинги, моделювати поїздку автомобіля й переглядати список нових книг.

Для виконання використано класи, об'єкти, методи, списки та цикли в Python.
