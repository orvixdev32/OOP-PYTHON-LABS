# Лабораторні роботи з Python

Цей репозиторій містить виконання лабораторних робіт.

## Структура проекту
* `lab1.py` — базові операції з числами та рядками в Python.
* `lab2.py` — умовні оператори та цикли.
* `lab3.py` — робота зі списками, кортежами та словниками.
* `lab4.py` — робота з файлами.
* `lab5.py` — вийнятки в Python.
* `lab6.py` — функції, модулі та робота зі списками в Python.
* `lab7.py` — ооп Частина 1
* `lab8.py` — ооп Частина 2
* `lab9.py` — Flask

## Як запустити
1. Встановіть Python 3.x.
2. Запустіть файл командною: bash
python oop-python-labs/labx/labx.py
x - номер лаб
